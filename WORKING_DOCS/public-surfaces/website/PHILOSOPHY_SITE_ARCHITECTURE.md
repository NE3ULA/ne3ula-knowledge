# Philosophy Site Architecture

This document captures the conceptual information architecture for presenting
NE3ULA philosophy on public surfaces.

It is a content-structure document, not an implementation spec.

## Recommended Page Order

1. Doctrine
2. Laws
3. Becoming
4. Functions
5. Sovereignty
6. Path
7. Principles

Principles should function as supporting or deeper reference material rather
than the first point of entry.

## Suggested Navigation

- Doctrine
- Laws
- Becoming
- Functions
- Sovereignty
- Path

## Suggested Route Flow

Doctrine -> Laws -> Becoming -> Functions -> Sovereignty -> Path

## Purpose of Each Section

- Doctrine explains what NE3ULA is.
- Laws condense the philosophical core.
- Becoming explains why the philosophy matters to a human being.
- Functions explain how the system works in motion.
- Sovereignty explains why the individual remains above the system.
- Path explains where doctrine becomes practice.

## Maintainer Notes

- philosophy pages should be modular
- canonical order should be explicit
- public simplification should not overwrite canonical ontology
- prefer merge into canonical docs over duplicate doc trees
- keep content reusable and source-aware
