# E3 Ebook V1 Source Map

Status: Canonical planning document for Ebook V1
Product role: E3 philosophy and human-readable MVP of the future AXZIO experience
Branch: `agent/ebook-v1-manuscript`

## Current Objective

Create the smallest complete, marketable, revenue-generating expression of E3:
a reader-facing book that communicates the philosophy, teaches the core human
engine, and lets a person manually perform the essential process that AXZIO will
later make adaptive.

The ebook is not an application specification. It should read as a clear,
human, mythic, practical work. Its underlying concepts and exercises must map
cleanly to the future application.

## Product Definition

Ebook V1 serves two functions at once:

1. It is the foundational reader-facing philosophy of E3.
2. It is the manual MVP of the future AXZIO application experience.

The migration from book to application should not require the participant to
learn a new system. AXZIO should retain the same concepts, language, progression,
and practices while adding memory, adaptive interpretation, sequencing,
instrumentation, and guided execution.

Application development is outside Ebook V1 scope and must not block launch.

## Recurring E3 Practice Loop

Each chapter should end with a lightweight practice using the same five
functions:

1. Reveal — What is happening?
2. Interpret — What does it show me?
3. Align — Who am I choosing to be?
4. Act — What is the next meaningful action?
5. Integrate — What will I retain, revise, or repeat?

This recurring structure is the book's manual interface and a direct bridge to
future AXZIO interaction design.
