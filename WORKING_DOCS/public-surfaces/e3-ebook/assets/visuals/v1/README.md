# NE3ULA E3 Ebook Visual Assets — V1

Eight canonical models are supplied in two reusable production-master formats:

- `*-reference`: fast-reading chapter reference graphic
- `*-diagram`: relational or process-oriented model

Every asset is available as:

- PNG — 1600 × 2000 pixels for ebook and social use
- SVG — scalable production master

## Included models

1. E3 Practice Loop
2. Human Battery
3. Four Pillars + Four Primitives
4. Identity Stack
5. RING
6. LifeMods Cycle
7. Alchemist Pyramid
8. Identity Launch Sequence

## Production guidance

- This directory preserves both reference and diagram formats as reusable
  production masters.
- The approved Ebook V1 release uses a curated subset of ten full-page visual
  plates.
- Include both formats only when they provide meaningfully different reader
  value; redundant reference/diagram pairs should not automatically be placed
  together.
- Pillars + Primitives and RING use one selected format in the approved book.
- Preserve aspect ratio when resizing.
- Do not place body text over the graphics.
- Use dedicated dark visual pages in the ebook.
- Validate final readability on a phone before publication.
- Future social or educational derivatives may use either format independently.
