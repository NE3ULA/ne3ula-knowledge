# WE ARE ALCHEMY — Audiobook Reader and Read-Along Files

This directory contains the non-audio companion materials for the Ebook V1 audiobook release.

## Files

- `WE_ARE_ALCHEMY_AUDIOBOOK_READER_V1.txt` is the speech-generation and text-to-speech (TTS) manuscript.
- `WE_ARE_ALCHEMY_AUDIOBOOK_READER_V1.md` is the formatted visual and read-along manuscript.
- `WE_ARE_ALCHEMY_READALONG_SEGMENTS_V1.json` is the synchronization-ready segment manifest.

## Manifest structure

The manifest contains 10 chapters, 216 navigable sections, and 1,695 stable narration segments. Each segment has a stable identifier and `start_ms` and `end_ms` fields. Timing fields remain `null` until final audio alignment is complete.

## Audio storage

MP3 audiobook renders are intentionally not stored in GitHub. Audio distribution and storage will be handled separately.
